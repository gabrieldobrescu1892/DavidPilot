# AI Proposal Generator

Adds an authenticated proposal workspace at `/admin/proposals`.

## Features
- Generate a bilingual proposal from a qualified lead
- Uses lead intelligence, conversation context, service recommendation and value range
- Editable proposal sections
- Saved proposal history in Supabase
- Print-optimized PDF export through the browser
- Proposal status foundation for future sending and e-signature workflows
