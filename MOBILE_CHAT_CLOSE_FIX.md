# Mobile chat close-button fix

This patch keeps the DavidPilot AI Consultant above the premium mobile navigation and pins its close button inside a sticky chat header.

## Test

1. Open the site on a narrow mobile viewport.
2. Open the AI Consultant.
3. Confirm the circular close button is visible in the upper-right corner.
4. Scroll the conversation and confirm the header and close button remain visible.
5. Open and close the mobile navigation, then reopen chat and verify it remains above the navigation layer.
